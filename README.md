# CareerFit AI

**내 경험을 근거로 채용공고를 분석하고, 자기소개서 작성과 지원 관리까지 연결하는 AI 취업 지원 서비스입니다.**

CareerFit AI는 단순히 자기소개서 문장을 생성하는 서비스가 아닙니다. 사용자가 등록한 프로필, 프로젝트 경험, 전공·자격증·어학 정보와 원본 자료를 먼저 정리한 뒤, 실제 근거가 있는 내용만 지원 과정에 활용하도록 돕습니다.

## 핵심 기능

### 프로필 관리

지원자의 기본 정보와 전공, 자격증, 어학, 보유 기술, 목표 직무를 한곳에서 관리합니다. 지원 분야가 여러 개라면 목적에 맞는 프로필을 추가로 만들어 데이터를 분리할 수 있습니다.

책, 멘토, 가치관, 성장 과정처럼 프로젝트 경험이 필요하지 않은 자기소개서 문항을 위한 `개인 소재`도 따로 저장할 수 있습니다.

### 경험 데이터베이스

PDF, PPTX, DOCX, TXT, MD 자료에서 프로젝트와 활동 경험을 추출합니다. 추출된 경험은 원문 근거와 함께 저장되며 사용자가 직접 내용을 수정할 수 있습니다.

수정할 때마다 새 버전이 만들어지므로 이전 내용을 비교하거나 복원할 수 있습니다. 실제 경험과 일치한다고 확인한 버전은 `Verified` 상태로 승인하여 이후 추천과 자기소개서 작성에 사용합니다.

### 채용공고 분석

채용공고 원문을 입력하면 다음 정보를 구조화합니다.

- 주요 업무
- 필수 역량과 우대 역량
- 기술 스택과 도구
- 도메인 지식
- 협업·행동 역량
- 핵심 키워드와 중요 문장

분석된 JD와 내 프로필·Verified 경험을 비교하여 가장 적합한 경험 TOP3와 역량 Gap을 보여줍니다. AI가 잘못 분류한 내용은 사용자가 직접 수정할 수 있습니다.

### 자기소개서 설계

자기소개서 문항을 분석하고, 문항의 평가 의도에 맞는 경험 또는 개인 소재를 추천합니다. 추천 결과를 바탕으로 개요를 만든 뒤 승인된 개요에서 Draft를 생성합니다.

작성 결과에는 다음 검사가 함께 제공됩니다.

- 문항 요구사항 충족 여부
- JD 핵심 내용 반영 여부
- 글자 수 제한 반영 여부
- 동일 경험의 과도한 반복 여부
- 수치와 사실 근거 확인
- 근거가 부족하거나 확인이 필요한 문장 표시

### 지원 관리

분석한 채용공고를 지원 건별로 정리하고 지원 상태, 마감일, 메모를 관리합니다. 해당 JD에서 작성한 자기소개서 문항과 Draft도 함께 연결됩니다.

## 처음 사용하는 방법

### 1. 프로필을 작성합니다

왼쪽 메뉴에서 `프로필`을 선택하고 지원에 활용할 정보를 입력합니다.

- 목표 직무와 산업
- 전공과 학력
- 자격증
- 어학 정보
- 기술과 도구
- 활동 및 기타 역량

프로젝트가 아닌 개인적인 질문에 활용할 내용이 있다면 같은 화면의 `개인 소재 보관함`에 등록합니다.

### 2. 경험을 등록합니다

`경험 관리`에서 프로젝트 보고서, 포트폴리오, 발표 자료, 경력 정리 문서 등을 업로드합니다. 여러 파일을 함께 선택할 수 있습니다.

파일을 저장한 뒤 분석할 문서를 선택하고 `경험 추출`을 실행하면 문서에 포함된 경험이 Experience Editor에 등록됩니다.

### 3. 추출 결과를 검토합니다

Experience Editor에서 다음 내용을 확인합니다.

1. `Original Evidence`에서 경험의 원문 근거를 확인합니다.
2. `AI Extracted Profile`에서 구조화된 경험 내용을 확인합니다.
3. `User Correction · Preference`에서 잘못된 내용과 활용 선호를 수정합니다.
4. `Version History`에서 수정 버전을 비교합니다.
5. 내용이 정확하면 해당 버전을 승인해 `Verified` 상태로 만듭니다.

Verified 경험만 추천에 사용되므로, 경험 추출 후에는 반드시 검토와 승인을 진행하는 것이 좋습니다.

### 4. 채용공고를 분석합니다

`JD 분석`에서 회사명, 지원 직무와 채용공고 전체 내용을 입력하고 분석을 실행합니다.

분석 리포트에서 추출된 요구사항을 확인한 뒤 `TOP3 추천 및 Gap Analysis 실행`을 누릅니다. CareerFit AI가 프로필 정보와 Verified 경험을 함께 비교하여 활용하기 좋은 경험과 부족한 역량을 보여줍니다.

### 5. 자기소개서 문항을 등록합니다

`자기소개서`의 `문항 등록`에서 다음 내용을 입력합니다.

- 대상 JD
- 자기소개서 문항
- 글자 수 제한
- 회사가 제공한 추가 안내

등록한 문항은 유형, 평가 의도, 중요 포인트, 필요한 이야기 요소와 피해야 할 내용으로 분석됩니다.

### 6. 사용할 경험을 선택합니다

`문항 분석 · 경험 추천`에서 문항에 적합한 경험을 확인합니다. 추천 순위가 높더라도 반드시 그 경험만 사용할 필요는 없습니다. 실제로 강조하고 싶은 경험을 직접 선택하거나 여러 경험을 함께 사용할 수 있습니다.

감명 깊게 읽은 책, 멘토, 가치관처럼 프로젝트가 필요 없는 문항은 프로필에 등록한 개인 소재를 사용합니다. 필요한 내용이 아직 없다면 개인 소재를 추가한 뒤 다시 진행합니다.

### 7. 개요와 Draft를 만듭니다

선택한 경험과 추가 메모를 바탕으로 Outline을 생성합니다. 개요의 흐름과 사용할 근거를 확인하고 필요한 부분을 수정한 뒤 승인합니다.

승인된 Outline을 선택하면 Draft를 생성할 수 있습니다. Draft가 만들어진 뒤에는 Fact Check와 품질 검사 결과를 확인하고, 부족한 문장만 직접 수정하거나 AI 부분 수정을 사용합니다.

### 8. 지원 현황을 정리합니다

`지원 관리`에서 각 지원 건의 상태, 마감일과 메모를 기록합니다. 공고별 자기소개서 작업 진행 상황도 함께 확인할 수 있습니다.

## 상태와 검사 결과 이해하기

### 경험 상태

- `AI Extracted`: 문서에서 처음 추출된 상태입니다.
- `User Editing`: 사용자가 내용을 수정한 상태입니다.
- `Verified`: 사용자가 실제 경험과 일치한다고 승인한 상태입니다.

### Fact Check 상태

- `Verified`: 등록된 프로필이나 경험 근거로 확인되는 문장입니다.
- `Needs Review`: 일부 근거는 있지만 표현이나 수치를 다시 확인해야 합니다.
- `Unsupported`: 등록된 자료에서 근거를 찾기 어려운 문장입니다.

`Needs Review`와 `Unsupported` 문장은 그대로 제출하기보다 실제 사실과 일치하는지 확인한 뒤 수정하는 것이 좋습니다.

## 활용 팁

- 경험은 프로젝트 하나로 제한하지 말고, 문항에 필요한 경우 여러 경험을 조합하세요.
- 수치, 역할, 사용 기술과 결과를 구체적으로 등록할수록 추천과 Draft 품질이 좋아집니다.
- 전공, 자격증, 어학 정보도 프로필에 충분히 입력해야 JD 매칭과 자기소개서 작성에 반영됩니다.
- 추천 TOP3에 하나만 표시되면 나머지 경험의 관련성이나 근거가 부족한 상태일 수 있습니다.
- `Verified 경험이 없습니다`는 경험이 없다는 뜻이 아니라, 아직 승인된 경험이 없거나 해당 문항에 사용할 근거가 부족하다는 뜻입니다.
- 글자 수 제한이 있다면 문항 등록 단계에서 정확히 입력하고, 생성 후 표시되는 실제 글자 수도 확인하세요.
- AI 결과는 완성본이 아니라 초안입니다. 본인의 말투와 실제 사실에 맞게 마지막 검토를 진행하세요.

## 데이터와 계정

회원가입한 계정마다 프로필과 지원 자료가 분리됩니다. 한 계정 안에서도 여러 프로필을 만들어 지원 직무별로 경험과 자료를 나누어 관리할 수 있습니다.

삭제 메뉴에서 경험, 개인 소재, JD, 문항, 개요와 Draft를 삭제할 수 있습니다. 연결된 하위 데이터가 함께 삭제될 수 있으므로 화면에 표시되는 삭제 범위를 확인한 뒤 진행하세요. 영구 삭제한 데이터는 복구할 수 없습니다.
